# Programmers Solutions

이 레포지토리는 프로그래머스의 코딩 테스트 문제 풀이들을 담고 있습니다.

## 구조

솔루션은 난이도별로(`lv0` ~ `lv5`) 정리되어 있습니다.
각 파일은 문제 번호를 이름으로 하고, 확장자가 풀이 언어를 나타냅니다(예: `lv2/43165.py`, `lv2/43165.java`, `lv2/157342.sql`).
같은 문제를 여러 언어로 풀었다면 번호가 같은 파일이 언어별로 함께 있습니다.

## 사용 언어

- Python: 알고리즘 문제의 기본 풀이 언어입니다.
- Java: 일부 알고리즘 문제는 Java로도 풀었습니다.
- SQL(MySQL): SQL 문제는 `.sql` 파일로 작성되어 있습니다.
